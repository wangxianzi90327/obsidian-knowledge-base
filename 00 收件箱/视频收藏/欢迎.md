# 欢迎来到我的知识库

这是一个用于管理视频收藏的 Obsidian 知识库。

## 目录结构

| 目录 | 用途 |
|------|------|
| 00 收件箱/视频收藏 | 飞书同步的视频来源笔记 |
| 10 项目 | 进行中的项目 |
| 20 长期领域 | 长期关注的知识领域 |
| 30 资料库 | 参考资料 |
| 40 知识笔记/标签主题 | 按标签组织的主题笔记 |
| 40 知识笔记/观点卡片 | 个人观点和思考 |
| 80 归档 | 已完成或不再活跃的内容 |
| 90 附件 | 图片、文件等附件 |
| 99 系统/模板 | 笔记模板 |
| 99 系统/同步配置 | 飞书同步配置和状态 |

## 使用流程

1. 手机分享视频链接 → 飞书机器人接收
2. 飞书多维表格暂存链接和标签
3. Agent 同步到 Obsidian（首次全量，后续增量）
4. 在 Obsidian 中浏览、搜索、关联知识
